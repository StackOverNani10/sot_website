# Screenshots reales de las apps (landing pages)

Coloca aquí los PNG de las pantallas reales para reemplazar los mockups dibujados.

## Formato
- **PNG**, vertical (portrait), pantalla completa.
- **Sin el marco del teléfono** (el sitio ya pone el marco). Con la barra de estado limpia.
- Alta resolución (captura directa del teléfono o del simulador/emulador).
- Relación de aspecto ~9:19–9:20 (cualquier captura de teléfono moderno sirve).

## Nombres esperados (3 por app)

### SOT Service (cliente) — tema azul
- `service-home.png`     → Home / búsqueda de servicios
- `service-tracking.png` → Seguimiento en vivo (proveedor en camino / mapa)
- `service-profile.png`  → Perfil o historial

### SOT Provider (proveedor) — tema violeta
- `provider-requests.png` → Solicitudes "Nuevas" (o el overlay de solicitud entrante con mapa)
- `provider-detail.png`   → Detalle del servicio con el mapa de zona
- `provider-earnings.png` → Dashboard de ganancias

Cuando estén los archivos aquí, avísame y los conecto en las landing pages.
